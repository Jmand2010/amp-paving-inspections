# AMP Paving Inspection

A job inspection, findings and corrective action form for AMP paving crews.

## What is in this repository
- `index.html` is the whole app: the quick walk, the full inspection, the temperature check, the corrective actions, the customer sign-off and the shout-outs.
- `README.md` is this file.

## Current limits
- Entries are saved only in the browser of the phone or computer that is using the form.
- Photos are not saved yet.
- Nothing is shared between devices until the Firebase version is built.

## Updating the app
Upload a new `index.html` using Add file > Upload files. Uploading a file with the same name replaces the old one.

## Safety rules for this repository
- Never upload passwords, private keys, or Firebase service-account files.
- Keep this repository private.
